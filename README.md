## Utilisation
1. Télécharger le CSV, puis l'ouvrir dans Excel, LibreOffice ou un éditeur de texte avec séparateur `; `.
2. Observer les deux exemples purement fictifs ; ils ne sont pas des ventes ni des données comptables de clients.
3. Utiliser les colonnes pertinentes à son activité, vérifier ses obligations et conserver les justificatifs originaux.

Une facture émise mais non encore payée **n'est pas un encaissement**. Le fichier présent est seulement un exemple pédagogique ; il ne fournit ni contrôle d'intégrité, ni garantie de datation, ni conformité comptable certifiée, ni système de facturation électronique agréé. Il ne remplace pas les démarches ou outils légalement exigés.
